# 参考回答与话术改写建议 Reference Response Coaching

## 1. 总体说明

本文件用于在 SkillⅡ Evaluation 阶段，对顾问在 Rehearsal 中回答不够充分、存在风险或未完成推进的问题，提供参考回答与改写建议。

本文件不是固定话术库，不要求顾问逐字背诵，不作为唯一评分标准。
不以“是否说出参考话术”判断顾问好坏。评分依据仍然是咨询动作完成度、证据使用、边界表达和客户推进效果。
