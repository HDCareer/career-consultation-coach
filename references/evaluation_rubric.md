# Evaluation Rubric｜验收评分标准

## 1. R1-R9流程评分规则

每个环节使用：

- `PASS`：该环节目标基本完成，客户可以继续被推进，没有明显风险。
- `PARTIAL`：完成了一部分，但存在遗漏、表达不清、推进不足或风险未处理。
- `FAIL`：未完成该环节关键动作，或出现明显误导、回避、强推、过度承诺等问题。

## 2. 能力矩阵1-5分规则

- 5分：表现稳定、自然、能基于case事实推进客户决策。
- 4分：整体合格，有小瑕疵，但不影响真实咨询推进。
- 3分：勉强可用，需要管理者提醒，真实咨询中有一定风险。
- 2分：明显不足，容易导致客户不信任或无法推进。
- 1分：严重不足，建议专项复练，不建议进入真实咨询。

## 3. 最终准备度100分建议计算

建议采用：

- 流程覆盖：40分
- 能力矩阵：40分
- 风险表达与边界：20分

分数解释：

- 85分及以上：可以进入真实咨询。
- 70-84分：可以进入，但需注意风险。
- 70分以下：不建议进入，必须专项复练。
- 出现一票否决项时，不论总分多少，都标记为“不建议进入真实咨询”。

## 4. 一票否决项

必须保留并强化以下红线：

- 承诺Offer。
- 承诺薪资。
- 承诺内推。
- 暗示保面试。
- 虚构岗位资源。
- 虚构客户经历。
- 把课程项目包装成真实商业成果。
- 把团队成果包装成个人成果。
- 报价与产品事实不一致。
- 客户明显未同频却强行促单。
- 无产品事实依据时编造价格或服务内容。
- 将高风险营销表达说成合同承诺。
- 编造退款、售后、家长沟通、优惠、定金、尾款或分期规则。
- 将内部推荐机会、投递管理或投递数量扩大成结果保证。

## 5. 产品事实专项评分

R7-R9 和 Follow-up 相关演练必须额外检查：

- 5分：能准确区分已确认事实、未确认事实和高风险营销表达，并能自然解释产品适配理由。
- 4分：产品范围基本准确，偶有不够清晰，但没有承诺结果或编造事实。
- 3分：能说出部分服务内容，但来源不清，价格或退款边界需要管理者提醒。
- 2分：多处混淆产品、服务次数、退款边界或营销表达，真实咨询风险较高。
- 1分：编造价格/服务/优惠，或承诺 Offer、薪资、内推、面试等结果。

## 6. Reference Response Coaching Scoring Boundary

`evaluation/05_reference_response_coaching.md` is a post-rehearsal training aid, not a separate script-memorization score.

When writing the final score:

- Do not reward or penalize consultants based on whether they can recite the reference answer.
- Do not judge consultant quality by whether they say the reference wording.
- Score the original Rehearsal performance by action completion, evidence use, boundary expression, product-fact accuracy, risk control, and customer progression effect.
- Use reference responses only to explain how `PARTIAL`, `FAIL`, high-risk, vague, boundary-unclear, or weak-closing answers can be improved.
- If the original answer is already strong, mark it as `本题回答可作为优秀表达候选` instead of forcing a rewrite.
- Reference responses must follow `references/reference_response_coaching_rules.md` and must not add customer facts, product facts, service commitments, Offer, salary, referral, or guaranteed interview implications.
