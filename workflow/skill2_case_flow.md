# SkillⅡ Case Flow

## Stage 1: Preparation

Start with `启动Preparation`.

Inputs:

- `input/pre_consultation_report.md`
- Optional `input/latest_context.md`
- Optional `input/participant_info.md`
- Job screenshots

Outputs:

- Preparation plan
- Job evidence matrix
- Direction evidence chain
- Consulting ammo bank
- Preparation status

## Stage 2: Rehearsal

Start with `开始Rehearsal`.

Before starting, require `participant_info.md`.

Run R1-R9 in order unless the consultant explicitly jumps. If a section is skipped, record the skip.

## Stage 3: Evaluation

Start when the consultant says `结束演练，开始验收` or R1-R9 are covered.

Outputs:

- Process coverage review
- Capability matrix review
- Risk expression review
- Manager review summary
- Pre-meeting battle card

## Stage 4: Follow-up Coaching

Start with `启动Follow-up Coaching` after a real consultation transcript is uploaded.

Outputs:

- Sales-view recap
- Customer conversion status
- Follow-up Action Plan
- Optional next-contact script
